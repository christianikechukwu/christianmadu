# Christian Ikechukwu Madu – Academic Portfolio (plain HTML, CSS & JavaScript)

No frameworks, no build step, no TypeScript.

- index.html, about.html, projects.html, planner.html, contact.html – the five pages
- css/style.css – the single stylesheet
- js/main.js – menu, footer year, scroll animations, pop-up windows (all pages)
- js/home.js, js/projects.js, js/planner.js, js/contact.js – page-specific features
- images/, audio/ – photos and the voice welcome

Open index.html in a browser, or upload the folder to any static host (GitHub Pages, Netlify, etc.).
